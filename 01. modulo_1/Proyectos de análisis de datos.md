# Proyectos de análisis de datos

## Análisis en tiempo real

### La revolución del análisis de datos

El objetivo principal del análisis de datos tradicional es presentar la información de una manera fácil de entender para los responsables de la toma de decisiones.

Los avances en la recopilación, almacenamiento y la recuperación de datos en tiempo real hacen posible el análisis de todo tipo de datos de muchas fuentes, como documentos, imágenes, entradas en medios sociales o sitios de comercio electrónico, e incluso sensores dentro de los electródomesticos.

Ejemplos de análisis avanzados:

- Un banco que analiza transacciones para identificar operaciones fraudulentas.
- Un fabricante que monitorea constantemente los informes de defectos para modificar los procesos de producción.
- Un minorista que responde inmediatamente a las reseñas de los clientes y ajusta los productos o las estrategias de ventas.

> Ahora en lugar de depender de desempeños pasados, las organizaciones pueden utilizar datos en tiempo real para lograr un objetivo.

### Diferentes tipos de análisis de datos

#### Análisis descriptivo - ¿Qué sucedió?

- Utiliza datos observados para identificar características clave en un conjunto de datos.
- Se basa en datos históricos para proporcionar informes sobre eventos pasados.

El proceso del análisis descriptivo es el siguiente:

1. Hacer una pregunta histórica que necesite una respuesta como ¿Cuanto del producto X vendimos el año pasado?.
2. Identificar los datos requeridos para responder la pregunta.
3. Recopilar y preparar datos.
4. Analizar datos.
5. Presentar resultados.

Ejemplos de análisis descriptivo:

- Resumen de eventos históricos como ventas, inventario o datos de operaciones.
- Comprender los datos de participación, como los Me gusta y No me gusta o el volumen de visitas a la página a lo largo del tiempo.

#### Análisis predictivo - ¿Qué podría suceder en el futuro?

- Utiliza datos en tiempo real o pasados para hacer predicciones basadas en probabilidades.
- Se puede utilizar para inferir datos faltantes o establecer una tendencia futura prevista.
- Utiliza modelos de simulación y pronósticos para sugerir lo que podría suceder en el futuro.

El proceos del análisis predictivo es el siguiente:

1. Hacer una pregunta con visión de futuro como ¿Podemos predecir la cantidad de producto X que venderemos el próximo año?.
2. Recopilar y preparar datos.
3. Desarrollar modelos de análisis predictivo.
4. Aplicar modelos a los datos preparados.
5. Revisar modelos y presentar resultados.

Ejemplos de análisis predictivo:

- Previsión del comportamiento del cliente, patrones de compra e identificación de tendencias de venta.
- Predecir las preferencias del cliente y recomendar productos en función de las compras anteriores y el historial de busqueda.

#### Análisis prescriptivo - ¿Qué se debe hacer a continuación?

- Dice lo que debe hacerse en una situación determinada.
- Ayuda a los ejecutivos, gerentes y empleados a tomar las mejores decisiones en función de los datos disponibles.

Ejemplo de análisis prescriptivo:

- Un buen ejemplo del análisis prescriptivo es el campo de las aplicaciones de mapas y direcciones basadas en GPS, ya que proporcionan opciones de ruta a un destino basadas en el vólumen de tráfico, las condiciones de carretera y la velocidad máxima.

#### Análisis de diagnostico - ¿Por qué sucedió esto?

- Mejora el proceso de análisis descriptivo al profundizar e intentar descubrir las causas.

EL proceso de análisis de diagnistico es el siguiente:

1. Identificar anomalías (inconsistencias) en conjuntos de datos.
2. Recopilar datos relacionados con las anomalías.
3. Utilizar técnicas estadísticas para descrubir las relaciones y tendencias que podrían explicar las anomalías.
4. Presentar posibles causas.

Ejmplos de análisis de diagnostico:

- El uso de la opción de cancelación de las suscripciones, correlacionadas con los comentarios y las calificaciones por parte de los clientes, para determinar los motivos de cancelación más comunes.
- Determinar si existe una correlación entre la demografía de los consumidores y sus patrones de compra en épocas específicas del año.

## Análisis de datos en acción

### Proceso de análisis de datos

#### Ciclo de vida de análisis de datos de seis pasos

Modelo iterativo que permite que algunos pasos puedan repetirse varias veces antes de que los responsables de la toma de decisiones tengan la confianza suficiente para avanzar al siguiente paso.

1. **Hacer la pregunta:** El proceso de análisis de datos empieza con una pregunta que debe responderse, por ejemplo, ¿que color de bicicleta es más popular entre los compradores jóvenes?, o preguntas complejas como ¿por qué ciertos tipos de células cancerosas presentan resistencia a los tratamientos de radiación?
2. **Obtener los datos:** Implica el proceso de localizar y obtener datos que sean relevantes para la pregunta y luego determinar si hay suficientes datos para completar el análisis.
3. **Investigar los datos:** Los datos vienen en muchas formas y de muchas fuentes. Este paso implica determinar si los datos estan completos y contienen la información relevante para el análisis.
4. **Preparar los datos:** Implica tareas con el fin de transformar los datos a un formato adecuado para la herramienta que se utilizará. Este proceso a menudo se conoce como limpieza de datos.
5. **Analizar los datos:** Es el proceso de identificación de patrones, correlaciones y relaciones contenidas en un conjunto o conjuntos de datos para extraer inferencias y conclusiones. A menudo el análisis se basa en técnicas estadísticas y herramientas de software, como hojas de cálculo y aplicaciones de visualización.
6. **Presentar los resultados:** Consiste en comunicar los resultados a los responsables de la toma de decisiones, a través de informe, representaciones gráficas o una combinación de ambos.
